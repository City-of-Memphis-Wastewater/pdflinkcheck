The ISO 32000 PDF specification defines objects, actions, destinations, annotations, dictionaries, and keys. It's authoritative but intentionally library-agnostic.

Library documentation (PyPDF, PDFium, PyMuPDF, etc.) explains each library's own API.

This package hope to offer a clear Rosetta Stone between the PDF engines offered. Not that pypdf inferred groups are the true representation of the standard, and key names used in PDFoum and PyMuPDF are expected to consume links with ultimately the same conclusions..
