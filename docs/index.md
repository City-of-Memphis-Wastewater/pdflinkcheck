# PDFLinkCheck Validation Software

PDFLinkCheck validates external hyperlinks and internal PDF navigation links, producing reports for automated documentation quality assurance.

See the `pdflinkcheck` Typer CLI structure.

```
pdflinkcheck helptree
```
